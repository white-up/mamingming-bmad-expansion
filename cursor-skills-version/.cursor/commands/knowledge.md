# 知识库生成 (Knowledge Generation)

## 概述
将日常沟通、问题排查记录转化为标准化的 QA 知识库条目。

## 执行步骤
1. **加载指令**: 读取 `jl-skills/instructions/knowledge/`。
2. **分析**: 提取问题场景、解决方案和关键步骤。
3. **优化**:
   - **标题**: 格式化为 `【模块】动作+对象`。
   - **内容**: 去除口语废话，确保步骤动词开头。
   - **结构**: 拆分为背景、方案、注意事项。
4. **输出**: 生成 Markdown 格式的知识条目。

## 快捷指令参数
- `/knowledge [文本]`: 将输入的文本转化为知识条目。
- `/knowledge batch`: 批量处理多个问题。
- `/knowledge refine`: 优化现有的知识条目。
