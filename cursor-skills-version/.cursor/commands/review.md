# 代码审查 (Code Review)

## 概述
启动全面的代码审查流程，覆盖合规性、架构、安全性和代码质量。

## 执行步骤
1. **加载指令**: 遵循 `jl-skills/instructions/review/` 下的指令文件。
2. **分析**: 扫描当前选中的代码或变更集。
3. **检查**:
   - [ ] **Java 规范**: 命名、日志、异常处理。
   - [ ] **架构设计**: 分层依赖、DDD 模式违规。
   - [ ] **安全性**: SQL注入、XSS、敏感信息。
   - [ ] **代码质量**: 复杂度、测试覆盖、性能隐患。
4. **报告**: 生成 Markdown 格式的审查报告。

## 快捷指令参数
- `/review full`: 执行完整审查（默认）。
- `/review quick`: 仅检查关键问题。
- `/review security`: 仅进行安全审计。
