# 快速改动 (Quick Fix)

## 概述
轻量级小改动流程，适用于快速修复、小功能调整等场景。相比 `/design` 流程更轻量，适合快速迭代。

## 执行步骤
1. **加载指令**: 读取 `jl-skills/instructions/quick-fix/`。
2. **需求明确**: 理解改动需求。
3. **变更分析**: 分析代码需要修改的位置和影响范围，生成变更分析报告。
4. **单元测试补充**: （如需要）为已有功能补充单元测试。
5. **代码修改**: 实施代码改动。
6. **测试验证**: 运行单元测试确认改动正确。
7. **生命周期提示**: 提示用户执行代码评审和文档更新。

## 快捷指令参数
- `/quick-fix [需求描述]`: 直接开始快速改动流程。
- `/quick-fix [文件路径]`: 针对指定文件进行改动分析。
