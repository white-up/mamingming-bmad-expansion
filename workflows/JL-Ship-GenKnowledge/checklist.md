# 知识库条目生成工作流 - 验证清单

## 输入内容验证

### 问题描述质量
- [ ] 问题描述清晰，无歧义
- [ ] 包含问题发生的场景或触发条件
- [ ] 如有错误码/提示信息，已明确记录
- [ ] 问题涉及的系统/模块已识别

### 解决方案质量
- [ ] 解决方案完整，可执行
- [ ] 包含所有必要步骤
- [ ] 步骤顺序正确
- [ ] 涉及的操作权限已说明

---

## 标题生成验证

### 关键词前置规则
- [ ] 业务模块使用【】标注并放在最前面
- [ ] 业务模块分类准确
- [ ] 示例：【订单售后】而非"关于订单售后"

### 拒绝口语化
- [ ] 无"请问"、"帮我"、"解决一下"等词汇
- [ ] 无"怎么办"、"能不能"等疑问句式
- [ ] 标题简洁专业

### 包含特征词
- [ ] 错误码已包含（如有）
- [ ] 错误提示文案已包含（如有）
- [ ] 特定系统/模块名称已包含

### 覆盖同义词
- [ ] 在括号中补充了可能的搜索关键词
- [ ] 同义词选择合理，覆盖常见搜索词
- [ ] 示例：（退款失败/拦截发货）

### 标题示例验证
| 检查项 | 通过 |
|-------|-----|
| 【业务模块】存在 | [ ] |
| 动作+对象结构清晰 | [ ] |
| 同义词扩展存在 | [ ] |
| 无口语化表达 | [ ] |

---

## 内容结构验证

### 问题背景（场景描述）
- [ ] 一句话描述问题发生场景
- [ ] 包含触发条件
- [ ] 语言简洁，无废话

### 解决方案（操作步骤）
- [ ] 步骤编号清晰（1. 2. 3.）
- [ ] 每步有加粗的步骤名称
- [ ] 每步以动词开头（点击/打开/选择/输入）
- [ ] 步骤可独立执行，顺序正确
- [ ] 无遗漏的关键步骤

### 注意事项
- [ ] 包含权限要求（如有）
- [ ] 包含避坑点/风险提示（如有）
- [ ] 包含前置条件（如有）

### 内容质量检查
| 检查项 | 通过 |
|-------|-----|
| 无客套话（"好的"、"已收到"） | [ ] |
| 无排查废话 | [ ] |
| 步骤动词开头 | [ ] |
| 结构化三模块完整 | [ ] |

---

## 去冗余化验证

### 需要删除的内容
- [ ] 无"好的"、"收到"等客套话
- [ ] 无"我看看"、"稍等"等过程性废话
- [ ] 无重复描述
- [ ] 无与解决方案无关的排查过程

### 需要保留的内容
- [ ] 关键的排查结论
- [ ] 问题根因说明
- [ ] 解决步骤详情
- [ ] 注意事项和风险提示

---

## 语义搜索优化验证

### 搜索匹配度
- [ ] 标题包含用户可能搜索的关键词
- [ ] 同义词覆盖常见表达方式
- [ ] 错误码/提示文案可直接搜索命中

### 分类准确性
- [ ] 业务模块分类准确
- [ ] 便于知识库分类检索

---

## 格式规范验证

### Markdown 格式
- [ ] 二级标题格式正确（## 开头）
- [ ] 加粗格式正确（**文字**）
- [ ] 列表格式统一
- [ ] 无多余空行

### 模板一致性
- [ ] 遵循知识库QA条目模板结构
- [ ] 各部分标题与模板一致
- [ ] 内容填充完整，无占位符

---

## 状态文件验证

- [ ] 包含所有生成的条目信息
- [ ] timestamps 记录准确
- [ ] entries_generated 列表完整
- [ ] outputs_generated 列表完整

## 完成标准

- ✓ 标题符合所有规则
