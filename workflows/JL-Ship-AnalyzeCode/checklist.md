# Java 代码逆向分析工作流 - 验证清单

## 上下文分析阶段验证

### 代码识别
- [ ] 正确识别分析目标（类/方法/模块）
- [ ] 代码范围界定清晰
- [ ] 代码类型判断准确（Controller/Service/Repository 等）
- [ ] 依赖关系初步识别

### 文档关联
- [ ] 检查是否存在相关设计文档
- [ ] 检查是否存在相关 PRD 文档
- [ ] 文档与代码的对应关系确认
- [ ] 如有文档，引用文档验证代码实现

### 用户角色确认
- [ ] 用户角色已明确（开发/架构/测试/业务）
- [ ] 分析重点已根据角色调整
- [ ] 用户关注点已记录

## 代码分析阶段验证

### 业务背景分析
- [ ] 用户故事（User Story）描述完整
- [ ] 业务背景用通俗语言描述
- [ ] 核心价值明确说明
- [ ] 涉及的业务模块已识别

### 业务流程分析
- [ ] 主业务流程步骤详解完整
- [ ] 流程图（Flowchart）使用 Mermaid 绘制
- [ ] 正常路径（Happy Path）描述清晰
- [ ] 关键分支路径已识别并描述

### 业务规则分析
- [ ] 前置校验规则表格完整
- [ ] 每条规则包含：字段/对象、校验规则、错误提示、备注
- [ ] 核心处理逻辑使用伪代码或逻辑描述
- [ ] 金额计算、状态判断等关键逻辑说明清晰

### 状态流转分析
- [ ] 状态流转涉及的对象已识别
- [ ] 状态流转图使用 Mermaid 绘制
- [ ] 状态流转表格包含：起始状态、触发动作、结束状态、触发条件
- [ ] 所有状态转换路径已覆盖

### 数据与接口分析
- [ ] 数据模型变更（新增/修改表）已识别
- [ ] 关键字段说明完整
- [ ] 接口定义包含：接口名称、请求方式、入参、出参
- [ ] 入参出参使用 JSON 格式示例

### 外部依赖分析
- [ ] 依赖的内部服务已列出
- [ ] 依赖的第三方接口已列出
- [ ] 依赖的中间件（MQ、缓存等）已列出
- [ ] 依赖的数据库表已列出

### 异常与边界处理
- [ ] 异常场景表格完整
- [ ] 每个场景包含：场景描述、处理方案、是否需要人工介入
- [ ] 网络超时、并发、数据不一致等常见场景已覆盖
- [ ] Sad Path 分析完整
