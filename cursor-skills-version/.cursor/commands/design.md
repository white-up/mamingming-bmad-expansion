# 产研统一设计 (DDD Design)

## 概述
启动端到端的领域驱动设计流程。

## ⚠️ 交互模式
此命令是**高度交互式**的。Agent 会在每个关键步骤暂停，等待您的确认。

## 启动方式

### 方式 1: 提供需求描述
```
/design 我需要设计一个订单管理系统，支持下单、支付、退款功能。
```

### 方式 2: 指定文档路径
```
/design 请分析 docs/prd.md 中的需求
```

### 方式 3: 直接启动 (Agent 会询问)
```
/design
```
Agent 会主动询问您的需求。

## 执行流程
1. **需求确认** -> 理解您的需求
2. **数据字典** -> 定义术语 (等待确认)
3. **业务规则** -> 提取规则 (等待确认)
4. **流程图** -> 可视化 (等待确认)
5. **事件风暴** -> 领域事件 (等待确认)
6. **DDD 建模** -> 聚合设计 (等待确认)
7. **TDD 落地** -> 代码骨架 (等待确认)
