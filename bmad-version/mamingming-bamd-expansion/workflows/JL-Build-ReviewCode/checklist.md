# 代码审查工作流 - 验证清单

## 代码规约检查阶段验证

### Java 命名规范
- [ ] 类名使用 UpperCamelCase
- [ ] 方法名使用 lowerCamelCase
- [ ] 常量名使用 UPPER_SNAKE_CASE
- [ ] 包名全小写
- [ ] 变量名语义明确，避免单字符
- [ ] 布尔变量使用 is/has/can 前缀

### 异常处理规范
- [ ] 无空 catch 块（No Swallow Exception）
- [ ] 异常信息包含上下文
- [ ] 正确使用 checked/unchecked 异常
- [ ] finally 块正确释放资源
- [ ] 异常链正确传递

### 日志规范
- [ ] 使用参数化日志（避免字符串拼接）
- [ ] 日志级别使用正确
- [ ] 敏感信息不出现在日志中
- [ ] 异常日志包含堆栈信息

### 注释规范
- [ ] 类级别有 JavaDoc 注释
- [ ] 公共方法有注释说明
- [ ] 复杂逻辑有行内注释
- [ ] 无过时或误导性注释
- [ ] TODO/FIXME 有跟踪

## 评分标准

### 总分计算
- 代码规约 (30%): 基础分 100，每个问题扣分
- 架构设计 (30%): 各维度评分 (1-5) 转换为百分制
- 安全性 (20%): 基础分 100，每个漏洞扣分
- 代码质量 (20%): 综合评估

### 通过标准
- **Pass (通过)**: >= 80 分，无严重问题
- **Conditional Pass (有条件通过)**: 60-79 分，或有 1 个严重问题
- **Fail (不通过)**: < 60 分，或有多个严重问题
